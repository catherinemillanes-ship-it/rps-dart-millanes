## Name

## Section

## Description
This is a simple two-player Rock, Paper, Scissors game made using Dart.
Each player enters their name and chooses rock, paper, or scissors.
The game checks who wins each round, keeps the score, and shows the final winner.

## How to Run

1. Open the project folder in the terminal.
2. Run this command:

dart rock_paper_scissors.dart
