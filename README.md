## Description
This is a simple two-player Rock, Paper, Scissors game made using Dart. The game is played in the console, where both players enter their names and choose between rock, paper, or scissors.

The program checks if the players enter a valid move and shows the result of each round. It also keeps track of the score of both players. Players can choose to play again or end the game.

When the game ends, the program shows the final score and announces the overall winner. The game also uses basic Dart concepts such as functions, lists, loops, conditions, user input, and null safety.

## How to Run

1. Open the project folder in the terminal.
2. Run this command:

dart rock_paper_scissors.dart
